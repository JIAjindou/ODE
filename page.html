Natura non facit saltus.

Nature does not make jumps.  — G. W. Leibniz, 1704

Actions should not jump either

A discrete policy predicts each chunk of actions on its own, so the motion jumps where chunks meet. ODE policy learns how the action changes and integrates it over the robot's physical time, so each action follows from the previous one.

04Keeps multi-modality

A sampled direction tilts the field toward one route, so ODE policy takes all four routes from the first epoch.

Method

ȧ(t) = fθ( a(t), st, zt )
at+k+1 = at+k + ∫ fθ dt

Learn the velocity of the action, then integrate it in short chunks (H = 8, RK4). The next chunk starts where the last one ended. Training matches the integrated path to the demonstration, without velocity labels.

Diversity head

The mode is decided by the direction in which integration sets off, so it is enough to randomize that direction.

Contractive perturbation

Some training chunks start off the demonstration, so the field learns to pull drift back.

Any control rate

The field lives in continuous time. One model runs at a finer rate by integrating with a smaller step.
